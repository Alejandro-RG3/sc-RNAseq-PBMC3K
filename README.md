# Single-cell RNA-seq analysis of PBMC3K immune cells

## Overview
This project analyzes a public 10x Genomics PBMC3K single-cell RNA-seq dataset using Seurat. The goal is to practice a complete scRNA-seq workflow including quality control, normalization, dimensionality reduction, clustering, marker detection, broad immune-cell annotation and exploratory inflammatory signature analysis.

## Motivation
I developed this project to strengthen my understanding of single-cell analysis workflows relevant to cardiovascular immunology and immune-cell state discovery.

## Dataset
- Public PBMC3K dataset from 10x Genomics
- Approximately 2,700 peripheral blood mononuclear cells
- Used in the official Seurat guided clustering tutorial

## Workflow
1. Data loading
2. Quality control
3. Normalization
4. Highly variable gene selection
5. PCA
6. Clustering
7. UMAP visualization
8. Marker gene identification
9. Broad cell-type annotation
10. Exploratory inflammatory signature scoring
